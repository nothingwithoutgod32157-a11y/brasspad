# BrassPad Apartments

Pads for rent and sale — search, map, save, tour, apply, message, and list. BrassPad now connects renters to Onramp Jobs so people can find reachable work and calculate what housing fits the income.

## Revenue path

- Keep renter browsing free.
- Build paid featured/verified placement for property owners.
- Send users to Onramp for reachable work, then back to the affordability tool.
- Route property and employer partnership leads through Divine Blood Co.

Open `index.html` locally. No build step.

Default city: Akron, OH. Switch Rent / Buy in the header.
